# OSMANX OMNICHAT v0.4.0 — OBSIDIAN ATELIER

**Релиз:** 3 ноября 2026 г.  
**Статус:** функциональный self-hosted MVP, проверенный на SQLite и в офлайн-браузере. **Не аттестован как production SaaS.**

## Что изменилось по-настоящему

### 1. Совершенно новый визуальный язык

Дизайн «Premium Obsidian Minimalism»: глубокий графит, тёплый нефритовый акцент, типографика Inter / системные шрифты без внешних загрузок, мягкие границы, спокойная сетка, анимации с поддержкой `prefers-reduced-motion`. Всё реализовано в `frontend/src/app.tsx` и `frontend/public/styles.css`, не заменено картинкой. Работают переключение светлой/тёмной темы, адаптивная навигация, мобильные списки и чат.

**Русский язык:** меню, статусы, поиск, настройки, подключения, автоматизация, команда, аналитика, карточка клиента, журнал событий, сообщения и виджет посетителя. Названия международных брендов и обозначения API/CRM оставлены собственными именами. Часть внутренних кодов ошибок сторонних API зависит от провайдера и может оставаться на английском до подключения настоящих аккаунтов.

Проверенные снимки реального браузера: `docs/preview-v04-command.png`, `docs/preview-v04-inbox.png`, `docs/preview-v04-mobile.png`, `docs/preview-v04-widget.png` и `docs/preview-v04-light.png`.

### 2. Центр управления

Новая страница **Центр управления**: активные диалоги, ожидание ответа, просроченные обращения по SLA, диалоги без ответственного, воспроизводимая «умная очередь» без AI, загрузка команды и распределение по каналам. Из очереди открывается настоящий диалог, а не демодекорация. Точное значение показателей относится к **последним 500 открытым перепискам, доступным текущей роли**. Это не глобальные показатели крупного контакт-центра; в UI сделана соответствующая пометка.

Алгоритм ранжирования прозрачен и не придумывает покупки, намерения или успешность переговоров. Детали: [COMMAND_CENTER.md](COMMAND_CENTER.md).

### 3. Рабочие действия и командная безопасность

- Четыре приоритета на диалог (`Срочно`, `Высокий`, `Обычный`, `Низкий`): хранение в SQL, фильтрация, сортировка, обновление с `expected_version` и ответом 409 на конфликт изменений.
- **Мои подборки:** сохраняемые на сервере наборы фильтров, командные пресеты для руководителей; валидация разрешённых полей без произвольных SQL; лимит 20 на пользователя.
- **История действий:** серверная выборка журнала по диалогу и организации, доступная только сотруднику с правами на переписку.
- Горячие клавиши `Ctrl/⌘+K` (поиск), `Ctrl/⌘+1` (центр), `Ctrl/⌘+2` (Inbox), `J/K` (навигация по диалогам), `Escape` (закрыть окно).
- Показатели SLA учитывают последнее входящее и последнее исходящее сообщение; не считают диалог ожидающим, если оператор уже ответил.

### 4. SQL для больших рабочих списков

- Выборка последних 500 релевантных диалогов с явной областью действия.
- Один агрегирующий запрос для последнего исходящего сообщения, только top-25 кандидатов сериализуются полными карточками.
- Композитные индексы для активной очереди, приоритетов и поиска последнего исходящего сообщения.
- Поиск переписок выполняется **до** `LIMIT` и привязан к `organization_id`; символы `%` и `_` считаются буквальными, а не SQL-шаблонами.
- Серверная авторизация на чтение/изменение приоритетов и подборок; оператор не может получить переписку коллеги по прямой ссылке.

### 5. Сохраняем наследие v0.3

Работают: собственный чат сайта (посетитель → Inbox → оператор → посетитель), деморежим, CRM, ответственный, заметки, шаблоны, автоматизация по правилам, журнал, защищённые сессии, транзакционная очередь ответов, осторожная обработка неоднозначных ответов провайдера, адаптерная система официальных платформ, статусы интеграций. Прежний код не заменён визуальной имитацией.

## Что намеренно не запускалось в этом релизе

1. **Не подключены реальные клиенты и аккаунты Авито, Instagram, WhatsApp.** Адаптеры и проверка ограничений существуют, но одобренных боевых разрешений/токенов нет.
2. **Не настроены приём денег, платежи, подписки через провайдера.** Серверные лимиты тарифов сохраняются, но оплат нет.
3. **Не развёрнут публичный сайт и не запущен production Docker/PostgreSQL.** Конфигурация присутствует, но целевая инфраструктура не проверялась.
4. **Не обновлён React 16.** Это важный блокер аудита безопасности перед работой с реальными клиентами: текущий офлайн-runtime не позволяет установить современные npm-пакеты.
5. Не завершены горизонтальное масштабирование очереди и rate limiting через Redis, нагрузочные испытания, accessibility audit, проверка восстановления резервных копий и внешний pentest.

**Оценка покрытия полного первоначального ТЗ: ~70%, не показатель production-готовности.** См. [STATUS.md](STATUS.md).
