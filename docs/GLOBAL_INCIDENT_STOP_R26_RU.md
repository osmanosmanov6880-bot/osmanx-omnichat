# Если нужно срочно остановить все отправки OSMANX

Этот инструмент предназначен для владельца или администратора бизнеса. Пользоваться им ежедневно не требуется.

**Остановка.** Откройте **«Контроль доставки»** → **«Остановить все исходящие»** → прочитайте предупреждение → подтвердите. Новые сообщения, отправленные сотрудниками через соцсети, остаются в очереди. Приём сообщений клиентов продолжает работать.

**Важно:** если запрос уже начал выполняться на стороне WhatsApp, Авито или другой площадки, его результат может стать известен позднее. Нельзя обещать, что такой запрос отменился. Не отправляйте повторно ответы со статусом **«Требует проверки»**, не сверившись с исходной соцсетью.

**Возобновление.** Сначала выясните причину инцидента и проверьте доступы сотрудников, ключи API и состояние площадки. Затем в «Контроль доставки» нажмите **«Возобновить все исходящие»** и подтвердите действие. Ответы пойдут по прежней безопасной очереди. Если отдельный аккаунт был остановлен ранее, он останется остановленным до отдельного решения.

**Кто может управлять:** только владелец и администратор компании; действия фиксируются в журнале. Менеджер видит предупреждение в переписке, но не может сам снять ограничение. Автоматического снятия общей аварийной остановки нет.
