# Дизайн-система Obsidian Silence

## Ориентир
Тот самый утверждённый пользователем тёмный референс — не изображение в качестве фона, а четырёхзонный React/CSS-интерфейс.

| Участок | Задача | Визуальное решение |
| --- | --- | --- |
| Основная навигация | Выбрать раздел | 250 px, без лишних статистических блоков, приглушённые иконки |
| Входящие | Найти клиента | 395 px, большой заголовок, поиск, один фильтр источника |
| Переписка | Быстро ответить | максимальная ширина, высокочитаемые пузырьки, крупное поле ответа |
| Клиент | Мини-CRM без отвлечения | 320 px, теги, стадия, сотрудник, следующий контакт |

## Палитра
- Canvas: `#0d0e15`
- Panel: `#14151b`
- Border: `#292832`

- Secondary text: `#b5b1be`
- Lilac accent: `#bea1ee`

- Outgoing message: `#41334f`
- Incoming message: `#26262f`

## Правила UX
- Один основной сценарий на экране — ответ клиенту.
- Фильтры, историю, заметки и шаблоны открываем по запросу.
- Не используем выдуманные показатели и не окрашиваем все элементы в яркие цвета.
- Отправка, поиск, CRM и действия остаются серверными, React отвечает за состояния.
- Телефон: сначала список, затем чат; карточка — отдельным выезжающим слоем.
- Все кнопки имеют работающие обработчики. Для универсальной отправки файлов, которая ещё не поддерживается, показывается честное ограничение, а не фиктивная отправка.
