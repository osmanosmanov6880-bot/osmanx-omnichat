# OSMANX OMNICHAT — инструкция для компании-клиента

**Версия 0.6.0.** У каждой организации свои аккаунты, сотрудники, сообщения и ключи. Вы не подключаете аккаунты через владельца платформы и не пересылаете ему пароли соцсетей.

## Четыре шага

1. Откройте OSMANX, нажмите **«Регистрация»**, введите название компании, своё имя, почту и длинный пароль. Не выбирайте деморежим для реальных аккаунтов.
2. Откройте **«Ещё разделы» → «Интеграции»**, выберите площадку и следуйте подсказкам. Подключение одного аккаунта не открывает другим компаниям доступ к нему.
3. После проверки токена или OAuth нажмите **«Настроить события»** (если доступно), настройте в кабинете платформы обратный адрес webhook, отправьте тестовое входящее сообщение.
4. В разделе **«Входящие»** откройте появившийся диалог и ответьте. Проверьте **в оригинальной соцсети**, что сообщение дошло; статус «токен проверен» этого не гарантирует.

## Что доступно для каждой площадки

| Источник | Тип аккаунта | Порядок |
|---|---|---|
| Авито | Бизнес-профиль с разрешением Messenger API | «Подключить Авито» → OAuth → «Синхронизировать» → проверить чтение сообщений → ответить |
| Instagram | Профессиональный Business или Creator, разрешение Direct | «Подключить Instagram» → авторизация Instagram Login → подписка на события → тестовый Direct |
| WhatsApp | WhatsApp Business **Platform / Cloud API**, не обычный личный номер | Предпочтительно «Подготовить Meta» → «Продолжить в Meta» → выбрать WABA/номер → зарегистрировать номер с 6-значным PIN → тестовое входящее и ответ |
| Telegram | Бот, созданный компанией через BotFather | «Подключить Telegram» → токен → «Настроить события» → написать боту → ответить из OSMANX |
| ВКонтакте | Сообщество и токен для сообщений | «Подключить ВКонтакте» → ID сообщества и токен → «Секрет Callback» → включить Callback API в VK → написать сообществу |
| MAX | Разрешённый официальный бот MAX | «Подключить MAX» → токен → подписка на HTTPS webhook → написать боту → ответить |
| Facebook Messenger | Facebook Page и доступ к Page messaging | «Подключить Facebook Messenger» → Facebook Login → выбрать страницу → подписать страницу на события → написать странице |
| Чат сайта | Собственный сайт организации | «Чат для сайтов» → создать виджет → указать разрешённые домены → скопировать код → проверить цикл сообщений |

Никакие боты не могут читать все ваши личные Telegram-чаты, личные DM произвольных пользователей Instagram или переписки обычных аккаунтов WhatsApp. Поддерживается только официально делегированный доступ.

## Условия успешного соединения

**Проверка аккаунта:** API подтверждает, что токен или разрешение относится к указанному боту, странице или номеру. Это ещё не значит, что приходит поток сообщений.

**Входящие:** официальная площадка доставляет подписанное webhook-событие (или успешная синхронизация Авито), после чего диалог появляется в Inbox. Система помечает факт проверки.

**Исходящие:** оператор отправляет ответ, OSMANX сохраняет результат API; финальную доставку необходимо сверить у самой площадки. Неопределённые отправки нельзя повторять автоматически.

**Если не подключается:** откройте карточку канала → «Диагностика» и проверьте следующий шаг; «Проверить права» подтверждает разрешённый доступ. Владелец/администратор может заменить токен либо отключить канал. Секреты не публикуются в интерфейсе для рядовых сотрудников.

## Несколько компаний у одного владельца

Откройте **«Настройки и тариф» → «Ваши компании»**. Создайте ещё одну компанию, либо переключитесь в существующую. Список клиентов, ключи, CRM и сотрудники у компаний разные. Один внешний аккаунт нельзя одновременно назначить двум компаниям: его нужно явно отключить в предыдущем пространстве.

## Ограничения релиза

- Авито, Instagram, WhatsApp и Messenger требуют **одобренных приложений**/тарифов/прав доступа. OSMANX сам не выдаёт доступ.
- Для настоящих OAuth/webhooks сервер платформы должен иметь **публичный HTTPS**, настроенное шифрование и стабильный адрес. На `127.0.0.1` нельзя принять callbacks большинства внешних сервисов.
- Внешние подключения в этом релизе проверялись только с имитацией HTTP API, а не с действительными токенами. Нельзя гарантировать работу конкретного аккаунта до интеграционной проверки.
- Сообщения с вложениями и WhatsApp-шаблонами имеют дополнительные ограничения, некоторые медиа-сценарии пока не готовы.

**Оператору:** после подключения достаточно открыть «Входящие», выбрать диалог и написать ответ. Социальная сеть определяется автоматически по диалогу.
