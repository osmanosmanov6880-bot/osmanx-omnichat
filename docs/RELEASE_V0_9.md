# OSMANX OMNICHAT v0.9 — Clarity First

**Дата:** 4 ноября 2026 года. **Статус:** локальный self-hosted MVP. Не развернут публично, не подключен к реальным аккаунтам, платежей нет.

## Задача релиза

Сделать повседневный путь понятным для предпринимателя, который не знает API, webhooks и CRM: **создать компанию → выбрать соцсеть или чат сайта → увидеть новое сообщение → ответить из OSMANX**. При этом не выдавать контрактные тесты за реальную доставку.

## Изменения в реальном коде

1. **`GET /api/quickstart`: фактическая подготовка компании.** Проверяется членство владельца/администратора, используется `organization_id` в каждой выборке. Три шага: канал создан, первое настоящее входящее сохранено, исходящий ответ записан. Тестовые сообщения не засчитываются как реальные. Поступление сообщения в базу не равнозначно успеху webhook у провайдера, а запись исходящего — не подтверждение прочтения клиентом.
2. **Первый вход после регистрации** открывает экран «Быстрый старт», а не пустой список сообщений. Во всех шагах есть одна очевидная кнопка; дополнительный путь — собственный чат сайта. Индикатор прогресса вычисляется на сервере, без пользовательских галочек.
3. **Интеграции без визуального шума:** компактный выбор Авито, Instagram, WhatsApp, Telegram, VK, MAX или Facebook Messenger, затем *одна карточка* выбранного канала. Пункт «Все каналы» сохраняет прежний обзор. HTTPS и ключ шифрования объединены в одну понятную предупреждающую секцию с подробностями по запросу.
4. **Черновик не теряется между диалогами:** текст ответа хранится в памяти открытой вкладки, возвращается после выбора другого клиента, обозначается «Черновик» в списке. Никакой записи текста в `localStorage`, файловую систему или на сервер до отправки. После закрытия вкладки текст исчезнет; это осознанный выбор для приватности.
5. **Безопасная повторная отправка:** браузер сохраняет один `client_nonce` для одинакового сообщения. Если API создал сообщение, а HTTP-подтверждение потерялось, повтор использует прежний nonce и не создаёт дубль. Синхронизация переписки подтягивает актуальную версию после конфликта. Одновременное повторное нажатие заблокировано.
6. **Меньше лишних действий:** быстрые фильтры «Все / Новые / Ожидают», чистое объяснение пустой папки, заметные переходы к подключению, понятные сетевые ошибки, русская кнопка «Изменить» для виджета сайта.
7. **Тёмный Obsidian Silence сохранён**, без рекламных блоков и анимированной перегрузки. Поддержаны 1512, 390 и 320 px.

## Фактически проверено

- **64 теста** `PYTHONPATH=backend pytest -q backend/tests`: авторизация, собственный tenant, роли, адаптеры на контрактных ответах, очередь и новые проверки быстрого старта.
- `tsc --project frontend/tsconfig.json` — TypeScript собран в `frontend/public/app.js`.
- `python scripts/register_v09_e2e.py` — регистрация кликом в Chromium приводит к реальному backend и трёхэтапному экрану.
- `python scripts/clarity_v09_e2e.py` — 1512/390/320 px, выбор одной соцсети, переключение диалогов с черновиком, ответ через настоящий FastAPI TestClient и симуляция потерянного HTTP-ответа **после реальной записи в базу** (ровно одно исходящее).
- `python scripts/quiet_ui_e2e.py` — сохранение ранее реализованных UI/CRM функций, desktop и мобильные экраны.
- Миграция Alembic изменений не требует: новая функциональность использует существующие таблицы.

Браузерная проверка использует локальный HTTP bridge, а не живой публичный сервер. Внешние API реально не вызывались, токены третьих лиц не предоставлялись.

## Что ещё препятствует production

- Старый React 16 в предсобранной офлайн-среде — требуется переход на поддерживаемый современный стек.
- Нет подтверждённых сквозных входящих/исходящих тестов с реальными аккаунтами каждой соцсети и разрешений Meta/Авито.
- Требуется публичный HTTPS и проверка webhook, шифрование токенов, production PostgreSQL/Docker, резервное восстановление, внешние security и нагрузочные тесты.
- Полная поддержка медиасообщений и внеоконных WhatsApp-шаблонов не реализована.
- Публикация и платежи отложены по решению владельца.

## Путь пользователя

Откройте `start_windows.bat` → `http://127.0.0.1:8000` → **Демоверсия** для знакомства или **Регистрация** для собственной компании. После регистрации откроется «Быстрый старт»; выберите соцсеть. «Интеграции» показывают только выбранный канал. Перейдите во «Входящие», выберите клиента, введите ответ и нажмите кнопку отправки. Вся работа команды остаётся в общем интерфейсе OSMANX, а данные каждой организации изолированы.
