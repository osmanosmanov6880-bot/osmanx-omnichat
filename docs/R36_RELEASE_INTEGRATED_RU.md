# OSMANX OMNICHAT R36 — интеграция поверх R35

## Основа

Исходный пользовательский ZIP: `OSMANX_OMNICHAT_R35_TENANT_FAIR_RECOVERY.zip`.
В отличие от ранней локальной R36 на базе v1.5, эта сборка **включает исходники R35**, его очередь и политику отказов.

## Крупные блоки реализации

1. **Остановка исходящих отправок (SQL fail-closed).** `dispatch_pauses` с компанией и каналом; защита `NOT EXISTS` при выборе и CAS-захвате задания. Входящие обращения продолжают работать. Пауза не отменяет уже выполняющийся HTTP-запрос.
2. **Прозрачные переходы отправок.** `delivery_transitions` записывает коды `claimed`, `api_accepted`, `hard_fail`, `uncertain`, `retry_scheduled`, `manual_accepted`, `manual_failed`, `operator_cancelled`, `operator_verified_retry`. В журнале нет текста сообщений, токенов или ошибок провайдера.
3. **Управление и диагностика.** `GET/POST /api/operations/dispatch-pauses`, `POST .../resume`, `GET .../delivery-events`, `GET .../delivery-telemetry`, `GET .../support-bundle` (no-store, ограничено ролями, агрегаты).
4. **OBSIDIAN UI и мобильная проверка.** Панель пауз, события, телеметрия и обезличенная поддержка; ручной браузерный сценарий Chromium на 1512, 390 и 320 пикселей.
5. **Миграция, регрессия и очистка.** Alembic `f36000a10001` поверх R35 `f35000a10001`. Очистка новых таблиц при retention и tenant deletion. Покрытие миграции заполненной базы и cross-tenant границ; CI workflow.

## Проверки

- R35 база: 305 серверных тестов, все прошли.
- R36 специфичные тесты: отдельный набор, включая отмену и повтор с явным подтверждением.
- Chromium: три разрешения.
- Проверка реальной PostgreSQL конкурентности, API конкретных провайдеров и production-деплой остаются отдельными этапами и не должны считаться подтверждёнными по локальным SQLite/Chromium тестам.

## Граница безопасности

Публиковать только исходники и файлы `.env.example`, **не** файлы `.env*` с секретами, базы SQLite/PostgreSQL, резервные копии, клиентские вложения и логи. Репозиторий пользователя на GitHub публичный; рекомендуется сменить visibility на private, пока не проведён независимый аудит.
