# OSMANX OMNICHAT R36 — интеграция поверх R35

Основа: пользовательский `OSMANX_OMNICHAT_R35_TENANT_FAIR_RECOVERY.zip` (408 файлов). Это R36 на исходниках R35, а не устаревшая ветка v1.5.

## Реализовано локально

1. SQL-таблица `dispatch_pauses`: временная остановка новых исходящих захватов по всей организации или по одному каналу; сохраняется проверка в SQL CAS. Уже запущенную внешнюю отправку это не отзывает.
2. SQL-таблица `delivery_transitions`: история технических статусов и ручных действий без текстов клиентских сообщений и токенов.
3. API `/api/operations/dispatch-pauses`, `/resume`, `/delivery-events`, `/delivery-telemetry`, `/support-bundle`; RBAC, изоляция организаций, агрегированные диагностические данные.
4. OBSIDIAN интерфейс с управлением паузой, историей и скачиванием отчёта. Проверен Chromium в 1512, 390 и 320 px.
5. Миграция Alembic `f36000a10001` (после R35 `f35000a10001`), очистка данных при retention и удалении организации, автоматические тесты и CI.

## Проверено

- Неизменённый R35: **305 тестов пройдено**.
- Интегрированная R36: **316 тестов пройдено** в полной регрессии; дополнительный тест контроля ручной отмены/повтора прошёл в отдельном 22-тестовом наборе.
- Alembic SQLite: `upgrade head` и `check` без расхождений.
- Chromium: три размера экрана, операции паузы и выгрузки отчёта.

## Не подтверждено

Боевые интеграции соцсетей, независимый аудит безопасности и PostgreSQL многоузловые гонки. Production-публикации приложения не было.
