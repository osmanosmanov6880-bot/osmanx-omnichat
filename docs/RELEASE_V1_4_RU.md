# OSMANX OMNICHAT v1.4 — Background Worker Assurance

**Дата:** 4 ноября 2026 года. **Статус:** локально проверенная сборка, не production SaaS.

## Результат — фактически внесённые изменения

**1. Наблюдаемость фоновой отправки.** Добавлена таблица `worker_heartbeats` и миграция Alembic `ee4a14b80001`. Каждый запущенный API-worker и отдельный worker регистрирует собственную запись. Независимый таймер обновляет отметку жизни; завершённые циклы и число обработанных заданий фиксируются отдельно. При штатном выключении запись помечается остановленной. Старые отметки удаляются по TTL.

Это позволяет различать **работает**, **запущен, но не завершал цикл**, **не отвечает**. Простая отметка процесса не считается доказательством успешной обработки сообщений. В API не выдаются хосты, worker ID, чужие объёмы сообщений и секреты.

**2. Встроенная диагностика для руководителя.** `/api/operations/overview` возвращает обезличенную сводку `worker`, возраст старейшего ожидающего задания `oldest_queued_seconds` и счётчики отправки только своей компании. На русскоязычном экране «Контроль доставки» появилась короткая плашка, которая объясняет следующий шаг. Плашка не заявляет о доставке клиенту только из-за успешного API-запроса.

**3. Подготовлена отдельная современная сборка.** Файлы `frontend/package.json`, `frontend/vite.config.ts`, `frontend/modern/index.html` и `frontend/src/modern-entry.ts` позволяют установить React **19.3.1** и Vite **8.3.5**, собрать альтернативную точку входа и включить её через `FRONTEND_MODE=modern`. Переход из старого `ReactDOM.render` осуществляется тонким совместимым адаптером на `createRoot`. Если новая сборка отсутствует, включённый modern-режим возвращает **HTTP 503**, а не скрытно загружает React 16.

**Важная граница:** здесь npm-реестр недоступен (`EAI_AGAIN`), поэтому React 19 **ещё не установлен и не испытан в браузере**. Проверенная локальная сборка продолжает использовать старый React 16. Путь перехода создан, но **обновление не завершено**. На GitHub Actions подготовлена независимая проверка установки и сборки; она ещё не запускалась и не доказана в этом выпуске.

**4. Мобильный интерфейс.** Убрана выступающая за левый край часть скрытого мобильного меню. Текущий тёмный UI и все существующие вкладки сохранены.

## Установка и обновление

Для нового локального запуска распакуйте архив; Windows: `start_windows.bat`, Linux/macOS: `./start_linux.sh`. Откройте `http://127.0.0.1:8000`, затем демоверсию.

При обновлении действующей копии **сначала сделайте резервную копию** SQLite/PostgreSQL, затем замените файлы программы и выполните миграцию:

```bash
PYTHONPATH=backend python -m alembic -c backend/alembic.ini upgrade head
```

База, ключи интеграций и `.env` не должны перезаписываться или попадать в Git. В новой версии в `Контроль доставки` можно проверить, работает ли фоновой обработчик. Не путайте этот индикатор с доказательством доставки пользователю в соцсеть.

Подробности: `docs/WORKER_HEALTH_RU.md` и `docs/REACT19_MIGRATION_RU.md`.
