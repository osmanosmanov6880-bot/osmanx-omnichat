# OSMANX OMNICHAT v0.7 — Obsidian Silence

**Дата:** 4 ноября 2026 г.  
**Назначение:** точная программная реализация утверждённого тёмного минималистичного референса, без генерации рекламного изображения, изменения внешних API или публикации.

## Где находится реализация

- `frontend/src/app.tsx` — рабочий React-интерфейс, интерактивные состояния, единый Inbox, редактирование CRM, новая доска сделок и тихий экран входа.
- `frontend/public/styles.css` — оформленная CSS-дизайн-система, адаптация ПК, планшета, мобильных устройств.
- `frontend/public/app.js` — пересобранный JavaScript, который запускается без Node.js на машине пользователя.
- `scripts/quiet_ui_e2e.py` — проверка реальных UI-действий в Chromium через настоящий FastAPI TestClient, без выхода в интернет.
- `docs/preview-v07-*.png` — снимки реального Chromium, НЕ генерация изображений.

## Реализовано визуально

1. Постоянная спокойная навигация слева, пять основных разделов, остальные в «Другие разделы».
2. Отдельная колонка входящих: заголовок, поиск, выбор канала, компактные карточки с узнаваемыми векторными обозначениями источников. Дополнительные фильтры раскрываются только по запросу.
3. Основная переписка: имя контакта, канал, сообщения, время, тонкие разделители, компактный композер, отправка с проверкой ограничений канала.
4. Карточка клиента справа: теги с добавлением/удалением, стадия сделки, ответственный, следующий контакт; дополнительные поля/тестовые сообщения скрыты за дополнительным раскрытием.
5. Настоящее меню действий: статус, приоритет, закрепление, захват диалога, заметки, история, шаблоны.
6. Мобильная версия: список переписок → активная переписка → карточка клиента по запросу. Проверены экраны 390 и 320 пикселей.
7. Новый минималистичный экран входа/регистрации/демоверсии вместо маркетингового дашборда.
8. Раздел «Сделки» с реальной сменой стадии через существующий API контактов, а не декоративная ссылка.

## Что проверено

- `tsc --project frontend/tsconfig.json`: успешно.
- `PYTHONPATH=backend pytest -q backend/tests`: **45 passed** (3 предупреждения DeprecationWarning в стороннем httpx).
- `python scripts/quiet_ui_e2e.py`: успешно для 1648×928, 390×844 и 320×700; горизонтальное переполнение — **0 px**.
- Через настоящий backend в браузере: открыть диалог, отправить сообщение, добавить/удалить тег, изменить стадию сделки, написать внутреннюю заметку, открыть доску сделок, отфильтровать Instagram и открыть карточку клиента на мобильном.
- Экран входа, переключение демоверсии/входа/регистрации: проверены Chromium.

**Как работает E2E:** браузер показывает настоящую сборку React и передаёт запросы обработчикам FastAPI через локальный TestClient. Внешние платформы не подключаются и не имитируются как реально доступные. Это не нагрузочный и не production-тест.

## Сохранённые возможности

Авторизация компаний, роли и изоляция данных, CRM, аналитика, автоматизация, интеграционные адаптеры (Авито, Instagram, WhatsApp, Telegram-боты, VK-сообщества, MAX-боты, Facebook Messenger), веб-чат сайта, журнал действий, WebSocket, доставка с контролем неоднозначных результатов — код предыдущего релиза не удалялся.

## Честные ограничения

- **Социальные сети:** без настоящих учётных данных, одобрений платформ, HTTPS и разрешений не подтверждена ни одна боевая интеграция. В демоверсии сообщения не уходят во внешние сервисы.
- **Вложения:** входящие вложения отображаются там, где адаптер их поддерживает; универсальная отправка файлов из нового поля ввода не завершена. Кнопка явно сообщает об ограничении.
- **Публикация / платежи:** не запускались по решению владельца проекта.
- **Безопасность:** React 16 в локальном vendor-пакете не обновлён; до работы с реальными клиентскими данными необходимо обновление и дополнительная оценка безопасности.
- **Сервер:** production Docker/PostgreSQL и внешние webhooks в рамках этого релиза не проверялись.

**Статус:** запуск и демо локально, приём/отправка тестовых сообщений и работа CRM — да. Коммерческое использование настоящих соцсетей — ещё нет.
