# Что означают статусы WhatsApp в OSMANX

Откройте **«Входящие»** и выберите переписку. Возле вашего ответа может быть один из статусов:

- **В очереди** — сообщение сохранено, но внешняя отправка ещё не началась.
- **Отправляется** — обработчик выполняет запрос к площадке.
- **Принято API** — платформа вернула подтверждение приёма запроса. Это **ещё не доказательство доставки**.
- **Отправлено** — официальное событие WhatsApp `sent`.
- **Доставлено** — официальное событие WhatsApp `delivered`.
- **Прочитано** — официальное событие WhatsApp `read`.
- **Проверить** — после сетевого сбоя результат неизвестен; не нажимайте повтор наугад.

Некоторые события приходят с задержкой или не приходят вовсе. R24 сохраняет их и сопоставляет с сообщением, даже если подтверждение от площадки пришло раньше ответа API. При этом OSMANX не придумывает доставку по отсутствующему событию.

Если вам нужно понять состояние очереди, откройте **«Другие разделы» → «Контроль доставки»**. Руководителю доступен счётчик квитанций за последние 24 часа: это **число полученных статусов**, а не число доставленных сообщений.

Не нужны новые ручные действия или дополнительные разрешения сотрудников. Запросы по-прежнему проходят через подключение компании, а события принимаются только по проверенной подписи площадки.
