# UI-дирекшн — «Focus Inbox»

Визуальная цель: оператор за 1–2 секунды должен распознать **кто написал, откуда написал и где ответить**. Поэтому главное действие имеет одну визуальную доминанту — переписку и поле отправки.

**Принципы:**

1. «Один экран — одно первичное действие». Скрыть сложные таблицы, CRM и статистику за отдельными пунктами меню.
2. Прогрессивное раскрытие: фильтры, карточка клиента и настройки диалога появляются по явному действию.
3. Отдельный цвет обозначает источник/статус, но не используется одновременно для всех элементов.
4. Читаемый основной текст от 12–14 px и ясные кликабельные области; доступность и достаточная контрастность остаются отдельной проверкой.
5. Ошибки API не маскировать цветом «успех»: отличать Demo Mode, проверенный токен, ожидающий webhook и подтверждённую доставку.
6. Минимум необходимых действий: выбрать диалог → ответить → (необязательно) изменить статус или клиента.

Ни одно исследование с приглашёнными психологами или живыми дизайнерами не проводилось. Это инженерная переработка с использованием UX-эвристик, а не заключение внешней экспертной комиссии. Оставшиеся проверки: пользовательские тесты с реальными операторами, контрастность WCAG, навигация с экранным диктором и нагрузка.
