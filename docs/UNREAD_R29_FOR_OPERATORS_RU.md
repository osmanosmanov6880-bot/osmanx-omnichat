# Непрочитанные сообщения в OSMANX — инструкция для оператора

**Что изменилось?** Если клиент напишет ещё одно сообщение в момент, когда вы открываете переписку, система **не скроет его** отметкой «прочитано».

Откройте «Входящие» → нужного клиента. Если сообщения не изменились, система отметит только открытую версию переписки. Если во время открытия пришёл новый вопрос, увидите уведомление: **«Появилось новое сообщение — оно осталось непрочитанным»**. Переписка обновится автоматически, а счётчик на карточке покажет актуальное число новых сообщений.

Для руководителя: счётчик непрочитанных обновляется атомарно в базе; при одновременной работе нескольких операторов одно событие не должно потерять уведомление другого. Сотрудник не может подтверждать чужие назначенные диалоги. Запоздавшая история из соцсетей не считается новым непрочитанным уведомлением.

Не путайте отметку **«Прочитано в Inbox»** с подтверждением **«Прочитано клиентом в соцсети»**: это разные события. Если в канале нет реального подтверждения от провайдера, OSMANX не должен приписывать его.
