# OSMANX OMNICHAT R20 — протокол проверки

**Дата:** 4 ноября 2026 года. **Среда:** Python 3.13, TypeScript 5.x, SQLite и headless Chromium. Внешние соцсети не подключены.

## Результат итоговой регрессии

**130 из 130 серверных тестов пройдены** (`PYTHONPATH=backend pytest -q backend/tests --disable-warnings`), время 129,43 с. Семь предупреждений не приводят к падению тестов. Выходной код — 0.

## Выполненные проверки

- **История сообщений:** 650+ сообщений с корректным обходом курсором до конца; порядок `(created_at,id)`; 300 сообщений с одинаковыми временными метками; новый ответ во время чтения; отклонение чужого ID и отсутствие доступа к неназначенным операторам диалогам.
- **Chromium R20:** реальный React-интерфейс + локальный FastAPI TestClient, 330 архивных сообщений. Первоначальная выдача 120, далее две порции. Сохранение прочитанной истории после семисекундного обновления. ПК 1512 px, мобильные 390 px и 320 px. Отсутствуют JS-ошибки и горизонтальный скролл.
- **WhatsApp-шаблоны R19:** повторная браузерная проверка в Chromium при 1512, 390 и 320 px; постановка одобренного шаблона в очередь через тестовый Meta-ответ.
- **Миграция:** существующие организация и канал сохранились после `alembic upgrade f19000a10001 → head`; индекс `ix_message_history_cursor` создан; `alembic check` не нашёл отличий между моделями и схемой.
- **TypeScript:** `tsc --project frontend/tsconfig.json` — успешно, `frontend/public/app.js` пересобран.

## Ограничения проверки

Ни одна из этих проверок не подтверждает отправку через настоящий WhatsApp, Instagram, Авито или другой официальный API. Настоящий PostgreSQL под нагрузкой, Docker, HTTPS, React 19 и независимый аудит безопасности остаются необходимыми до коммерческого запуска.

R20 продолжает восстановленную R19, которая не являлась побайтовым восстановлением недоступного архива v1.8. **Перед обновлением действующей установки сделать резервную копию и сверить миграции**, не подменять последнюю рабочую базу из ZIP.
