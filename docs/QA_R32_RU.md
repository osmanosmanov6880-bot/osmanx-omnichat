# QA R32 — протокол испытаний

Дата: 5 ноября 2026. Проект: восстановленная ветка OSMANX OMNICHAT R19–R32.

## Проверяемые сценарии

- Пауза всей компании, продолжение записи подписанных webhook без создания новых сообщений, возобновление обработки.
- Независимая пауза одного live-канала и отсутствие влияния на соседний канал.
- Потерянный захват перед проверкой паузы корректно возвращается в очередь без расхода лимита попыток.
- Отказ в управлении роли lead и защита каналов другой компании.
- Переполнение очереди, HTTP 503 + Retry-After, сохранение уже подтверждённых событий и допуск дубликатов при заполнении.
- Изоляция порога по каналу, пакетный возврат до 20 задач, проверка аудита, повторный запрос без дублирования.
- Отказ в восстановлении после 14 дней, устойчивая пагинация по `(created_at,id)` с одинаковыми временными метками.
- Реальный локальный Chromium: пауза → подписанный тестовый webhook → возобновление → пакетный повтор → появление сообщений в Inbox. Три размера: 1512, 390 и 320 px.
- Миграция заполненной R31-базы к R32 с сохранением компании, канала и старой записи очереди.

## Команды

- `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONPATH=backend:. pytest -q backend/tests/test_r32_inbound_operations.py`
- `PYTHONPATH=backend python scripts/run_isolated_regression.py`
- `PYTHONPATH=backend python scripts/browser_r32_inbound_control.py`
- `PYTHONPATH=backend python scripts/verify_r32_migration.py`
- `DATABASE_URL=sqlite:///./ci-schema.db alembic -c backend/alembic.ini upgrade head`
- `DATABASE_URL=sqlite:///./ci-schema.db alembic -c backend/alembic.ini check`
- `tsc --project frontend/tsconfig.json`

**Непроверенное локально:** PostgreSQL 16 с несколькими независимыми процессами и SQL `FOR UPDATE` (сценарий `scripts/verify_r32_postgres.py` добавлен в CI); реальные webhook-доставки провайдеров, production, React 19, платежи.

## Финальная регрессия

Сводка по отдельным модулям автоматически сохраняется в `docs/qa_r32_module_results.json`. Итог тестов следует считать подтверждённым только если `all_exit_zero=true` и каждый модуль завершился с кодом 0. При несовпадении необходимо исправить причины до выдачи релиза.
